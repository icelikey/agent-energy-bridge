# Plan 03: 免费模型降级 + buildContext 注入

## Objective

在 `RefuelOrchestrator.prepareSession()` 中实现余额耗尽时强制降级到免费模型（FUEL-03），并在 `buildContext()` 中注入 `notificationService`，使 AutoRefuelDecorator 和 RefuelOrchestrator 能在服务器启动时自动获得通知能力。

## must_haves

```yaml
truths:
  - 降级逻辑：balance.availableUsd <= 0 时，effectiveModel = freeModel，degraded = true
  - 降级后 status 强制为 'ready'（guardDecision.allowed || degraded ? 'ready' : 'blocked'）
  - freeModel 默认值：process.env.AEB_FREE_MODEL || 'gemini-2.5-flash-free'
  - 降级事件通过 notificationService.sendFromEnv() 发送（fire-and-forget）
  - buildContext() 新增 notificationService 字段
  - NotificationService 从 src/service/notification-service.js 导出，已在 src/index.js 中导出
```

## Tasks

### Task 1: 扩展 RefuelOrchestrator 支持免费模型降级

<read_first>
- src/service/refuel-orchestrator.js — prepareSession() 完整实现，构造函数参数
</read_first>

<action>
在 `src/service/refuel-orchestrator.js` 中：

1. 在构造函数 `this.defaultDocsTemplate` 赋值之后添加：
```js
    this.freeModel = options.freeModel || process.env.AEB_FREE_MODEL || 'gemini-2.5-flash-free';
    this.notificationService = options.notificationService || null;
```

2. 在 `prepareSession()` 方法中，找到 `const refuel = await this.handleLowBalance(...)` 调用之后，在 `const energyInsights = ...` 之前插入：

```js
    // FUEL-03: 余额耗尽时强制降级到免费模型
    const availableUsd = Number(balance.availableUsd ?? balance.balanceUsd ?? 0);
    let effectiveModel = selectedModel;
    let degraded = false;
    if (availableUsd <= 0) {
      effectiveModel = this.freeModel;
      degraded = true;
      if (this.notificationService) {
        this.notificationService.sendFromEnv({
          type: 'balance_exhausted_fallback',
          level: 'critical',
          title: 'Balance exhausted — switched to free model',
          message: `Switched from ${selectedModel} to ${effectiveModel}`,
          meta: { originalModel: selectedModel, freeModel: effectiveModel },
        }).catch(() => {});
      }
    }
```

3. 将 `return { ... }` 中的 `status` 和 `selectedModel` 字段修改为：
```js
    return {
      status: guardDecision.allowed || degraded ? 'ready' : 'blocked',
      selectedModel: effectiveModel,
      degraded,
      recommendation,
      routingPlan,
      guardDecision,
      usage,
      balance,
      refuel,
      energyInsights,
    };
```
</action>

<acceptance_criteria>
- 构造函数包含 `this.freeModel` 和 `this.notificationService`
- `prepareSession()` 包含 `availableUsd <= 0` 降级分支
- `prepareSession()` 返回值包含 `degraded` 字段
- `prepareSession()` 返回值的 `status` 使用 `guardDecision.allowed || degraded` 逻辑
- `prepareSession()` 返回值的 `selectedModel` 使用 `effectiveModel`（降级后为 freeModel）
</acceptance_criteria>

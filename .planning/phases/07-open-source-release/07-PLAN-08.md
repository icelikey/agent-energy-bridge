创建文件 `.github/workflows/docker-publish.yml`，**逐字写入**：

```yaml
name: Docker Publish

on:
  push:
    tags:
      - 'v*'
    branches:
      - main

permissions:
  contents: read
  packages: write

concurrency:
  group: docker-publish-${{ github.ref }}
  cancel-in-progress: false

jobs:
  build-and-push:
    name: Build and push to GHCR
    runs-on: ubuntu-latest

    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Set lowercase repository name
        id: repo
        run: |
          REPO_LC="${GITHUB_REPOSITORY,,}"
          echo "lowercase=${REPO_LC}" >> "$GITHUB_OUTPUT"

      - name: Set up Docker Buildx
        uses: docker/setup-buildx-action@v3

      - name: Log in to GitHub Container Registry
        uses: docker/login-action@v3
        with:
          registry: ghcr.io
          username: ${{ github.actor }}
          password: ${{ secrets.GITHUB_TOKEN }}

      - name: Extract Docker metadata
        id: meta
        uses: docker/metadata-action@v5
        with:
          images: ghcr.io/${{ steps.repo.outputs.lowercase }}
          tags: |
            type=raw,value=latest,enable={{is_default_branch}}
            type=semver,pattern=v{{version}}
            type=sha,prefix=sha-,format=short
          labels: |
            org.opencontainers.image.title=Agent Energy Bridge
            org.opencontainers.image.description=Generic energy bridge for AI gateways
            org.opencontainers.image.licenses=MIT
            org.opencontainers.image.source=https://github.com/${{ github.repository }}

      - name: Build and push
        uses: docker/build-push-action@v6
        with:
          context: .
          file: ./Dockerfile
          platforms: linux/amd64
          push: true
          tags: ${{ steps.meta.outputs.tags }}
          labels: ${{ steps.meta.outputs.labels }}
          cache-from: type=gha
          cache-to: type=gha,mode=max
          provenance: false
```

**严格要求（必须遵守，按 RESEARCH §Pitfall 2/3 防御）：**

1. **小写化仓库名**：`GITHUB_REPOSITORY` 含 owner/repo 可能大写；ghcr.io 镜像名必须小写。`${GITHUB_REPOSITORY,,}` 是 bash 语法做 lowercase 转换；不要写 `${{ env.GITHUB_REPOSITORY }}` 或 `${{ github.repository }}` 直接用（per RESEARCH §A3）
2. **`permissions: packages: write`** 显式声明 — 否则 push 被拒（per RESEARCH §Pitfall 2）
3. **触发器同时含 `tags:` 和 `branches:`** — D-07/D-08 锁定的 3 种 tag 中 `latest` 仅 main push 触发，`vX.Y.Z` 与 `sha-XXX` 由 tag push 触发
4. **metadata-action tags 三行配置（必须按以下顺序）**：
   - `type=raw,value=latest,enable={{is_default_branch}}` — 仅 main push 时生效（per D-08）
   - `type=semver,pattern=v{{version}}` — **带 v 前缀**（per RESEARCH §A8、§Open Questions #1，CONTEXT.md D-08 明示 "v0.1.0"）
   - `type=sha,prefix=sha-,format=short` — 短 sha（per D-08）
   - **不要**添加 `type=semver,pattern={{major}}` —— 项目 0.x 期会产生无意义的 `:0` tag（per RESEARCH §Pitfall 3）
5. **`platforms: linux/amd64`** — v0.1.0 单平台（per RESEARCH §Open Questions #2、§Pattern 3 注释）；arm64 留到 v0.2
6. **`provenance: false`** — Docker Buildx 0.10+ 默认启用 attestations，会在 ghcr 产生额外 manifest；关闭以减少首次发布的复杂度
7. **`cache-from: type=gha` + `cache-to: type=gha,mode=max`** — 使用 GitHub Actions cache，加速重复 build
8. **OCI labels** — 通过 metadata-action labels: 字段为镜像注入元数据；不要在 Dockerfile 里硬编码 LABEL
9. **`concurrency.cancel-in-progress: false`** — Docker push 中途取消会留下半成品 manifest（per RESEARCH §Pitfall 6）
10. **不要**使用 `docker login` 手动写 shell 命令；用 `docker/login-action@v3`
11. **不要**给 `docker/login-action@v3` 用 `${{ github.repository_owner }}` 作为 username（per RESEARCH §A3）；用 `github.actor` 更安全
12. **不要**给 Dockerfile 改任何东西（README.en.md / docker-compose.yml 已稳定）

**首次发布后用户需做的事**（不在本 plan 范围，但 checkpoint 中要提醒）：

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ghcr.io 镜像仓库 | 公开后任何人可 pull；镜像层可被解构提取其中包含的代码与配置 |
| GitHub Actions runner | ubuntu-latest 是共享 runner，构建过程可被监听（理论上） |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-20 | Information Disclosure | 镜像层中的 .env 等敏感文件 | mitigate | Dockerfile 仅 `COPY src/ scripts/ bin/` — 不复制 `.env*` / `docs/private-*`；`.gitignore` 已排除运行时 `.env` |
| T-07-21 | Tampering | docker action 供应链 | mitigate | 所有 docker action 锁定到 `@v3`/`@v5`/`@v6` 主版本号（per RESEARCH §State of the Art） |
| T-07-22 | Spoofing | 用 `${{ github.actor }}` 推送 — fork 用户触发的 workflow 可能用错 actor | mitigate | `permissions: packages: write` 仅在 push（不是 pull_request_target）时生效；fork PR 默认无 write 权限 |
| T-07-23 | Elevation of Privilege | GITHUB_TOKEN scope | mitigate | top-level permissions 最小化（`contents: read` + `packages: write`，无 actions/deployments/issues 等） |
| T-07-24 | DoS | concurrent docker push race | mitigate | `concurrency.group` 限定到 ref；`cancel-in-progress: false` 避免半成品 manifest（per RESEARCH §Pitfall 6） |
</threat_model>

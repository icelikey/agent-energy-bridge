## User Setup Required

**Before pushing v0.1.0 tag, user must:**

1. Verify `Settings -> Actions -> General -> Workflow permissions = Read and write permissions`
2. (Optional but recommended) Push dry-run tag to validate workflow:
   ```bash
   git tag v0.1.0-rc1 -m "Release candidate 1"
   git push origin v0.1.0-rc1
   ```
3. After dry-run success, delete rc tag and push official release:
   ```bash
   git push --delete origin v0.1.0-rc1
   git tag -d v0.1.0-rc1
   git tag v0.1.0 -m "Release v0.1.0"
   git push origin v0.1.0
   ```

创建目录 `.github/workflows/`（如不存在），然后创建文件 `.github/workflows/ci.yml`，**逐字写入以下内容**（不要修改字段名、缩进、版本号）：

```yaml
name: CI

on:
  pull_request:
    branches: [main]
  push:
    branches: [main]

permissions:
  contents: read

concurrency:
  group: ci-${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: true

jobs:
  test:
    name: Test (Node ${{ matrix.node }})
    runs-on: ubuntu-latest
    strategy:
      fail-fast: false
      matrix:
        node: [20, 22]

    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Setup Node.js ${{ matrix.node }}
        uses: actions/setup-node@v4
        with:
          node-version: ${{ matrix.node }}

      - name: Verify Node version
        run: node --version

      - name: Run unit tests
        run: node --test

      - name: Verify module exports
        run: node -e "const bridge=require('./src'); const keys=Object.keys(bridge); if (keys.length===0) { console.error('No exports'); process.exit(1); } console.log('Exports:', keys.join(', '));"

  secrets-scan:
    name: Secrets Scan
    runs-on: ubuntu-latest
    permissions:
      contents: read

    steps:
      - name: Checkout (full history)
        uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - name: Run gitleaks
        uses: gitleaks/gitleaks-action@v2
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          GITLEAKS_CONFIG: .gitleaks.toml
          GITLEAKS_ENABLE_COMMENTS: true
          GITLEAKS_ENABLE_SUMMARY: true
```

**写入说明（必须严格遵守）：**

1. **不要**给 `node` matrix 用引号包裹数字（`[20, 22]` 是 number 类型；`['20', '22']` 是 string 类型；`actions/setup-node@v4` 文档推荐 number）
2. **不要**添加 `cache: 'npm'` 字段 — 本项目零依赖，缓存收益负面（多一次缓存查找 IO）；CONTEXT.md §Pattern 1 已确认可省
3. **不要**给 secrets-scan 添加 `if: github.event_name == 'push'` 等条件 — gitleaks 在 PR 也应跑（保护 fork 进来的 PR）
4. **fetch-depth: 0** 仅在 secrets-scan job 中需要；test job 用默认浅克隆即可（无需 git 历史）
5. **GITLEAKS_LICENSE 字段** — 个人账户不需要，org 仓库才需要；CONTEXT.md §Pattern 1 已确认本项目无需此 secret
6. **concurrency 组**取消同 PR 的过期运行，减少 CI 时间浪费
7. **GITLEAKS_ENABLE_COMMENTS** 让 gitleaks 在 PR 上自动评论发现，gitleaks-action@v2 默认行为
8. **GITLEAKS_CONFIG 路径**：写 `.gitleaks.toml`（相对仓库根的路径）；不要写绝对路径

**目录创建**：
- 如果 `.github/` 目录不存在，先创建 `.github/workflows/`
- 不要 commit 空目录占位文件（.gitkeep / .keep 等）

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub Actions runner | 第三方 action 可读 GITHUB_TOKEN，需最小权限 |
| PR fork → main | fork 的 PR 可注入恶意 yml 变化（如改 ci.yml 本身） |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-12 | Tampering | Action 供应链 | mitigate | 全部 action 锁定到主版本 `@v4`/`@v2`，不使用 `@main`/`@latest`（per RESEARCH §State of the Art） |
| T-07-13 | Elevation of Privilege | GITHUB_TOKEN 权限 | mitigate | top-level `permissions: contents: read`；secrets-scan job 不需 write 权限 |
| T-07-14 | Information Disclosure | PR 中新增密钥未被扫描 | mitigate | gitleaks-action 跑在每个 PR 上（包括 fork PR） |
| T-07-15 | DoS | concurrent CI runs | mitigate | `concurrency` group `cancel-in-progress: true` 取消过期 PR commit 的 CI |
</threat_model>

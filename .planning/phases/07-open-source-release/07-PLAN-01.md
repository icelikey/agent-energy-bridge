# Plan 01: 安全修复 — notify/test 认证

> **Note (revision 2026-05-11):** 本 plan 交付 **D-14**（X-API-Key 认证中间件，Phase 7 锁定的先决决策），**不对应任何 OPEN-XX 需求**。CONTRIBUTING.md（OPEN-01）由 PLAN-04 交付。本 plan 已 ship 至 main；timing-unsafe 比较的强化由 PLAN-02 新增任务处理。

## Objective

在 `POST /agent/v1/notify/test` 端点添加 X-API-Key 认证保护，使其与其他管理端点保持一致的访问控制策略。创建可复用的 `auth-middleware.js`，为后续其他管理端点扩展认证做准备。

## must_haves

```yaml
truths:
  - POST /agent/v1/notify/test 必须校验 X-API-Key header
  - 认证失败返回 401 Unauthorized（不是 403，因为是身份认证失败）
  - API Key 通过环境变量 AEB_API_KEY 配置，遵循项目 AEB_ 前缀命名规范
  - 未配置 AEB_API_KEY 时，认证中间件允许所有请求通过（开发友好）
  - buildContext() 注入 apiKey 字段
  - 认证中间件遵循现有中间件模式：(request, response, context) → void/throw
  - 零外部依赖，纯 Node.js 内置模块
  - 测试覆盖：有 key 时通过、key 错误时 401、无 key 配置时通过
```

<action>
创建文件 `src/server/middleware/auth-middleware.js`：

```js
function createAuthMiddleware(options = {}) {
  const apiKey = options.apiKey || process.env.AEB_API_KEY || null;

  return function authMiddleware(request, response, context) {
    // 未配置 API Key 时跳过认证（开发友好）
    if (!apiKey) return;

    const providedKey = request.headers['x-api-key'] || request.headers['x-api-key'] || null;

    if (providedKey !== apiKey) {
      const error = new Error('Unauthorized: invalid or missing API key');
      error.statusCode = 401;
      error.code = 'UNAUTHORIZED';
      throw error;
    }
  };
}

module.exports = { createAuthMiddleware };
```

> **Revision note (2026-05-11):** 上方代码片段中 `request.headers['x-api-key'] || request.headers['x-api-key']` 是冗余 OR（Warning 6），且 `providedKey !== apiKey` 是 timing-unsafe（Blocker 2）。两者均已 ship 至 main；强化任务由 **PLAN-02 Task 0**（"Upgrade api-key-auth middleware to use crypto.timingSafeEqual"）在 Wave 1 内、SECURITY.md 公布前完成。本 plan 的历史文本不再回改。
</action>

```js
const test = require('node:test');
const assert = require('node:assert/strict');
const { createAuthMiddleware } = require('../src/server/middleware/auth-middleware');

test('auth middleware passes when no API key configured', () => {
  const middleware = createAuthMiddleware({ apiKey: null });
  assert.doesNotThrow(() => middleware({ headers: {} }, {}, {}));
});

test('auth middleware passes with correct X-API-Key', () => {
  const middleware = createAuthMiddleware({ apiKey: 'secret-123' });
  assert.doesNotThrow(() => middleware({ headers: { 'x-api-key': 'secret-123' } }, {}, {}));
});

test('auth middleware throws 401 with wrong X-API-Key', () => {
  const middleware = createAuthMiddleware({ apiKey: 'secret-123' });
  assert.throws(
    () => middleware({ headers: { 'x-api-key': 'wrong' } }, {}, {}),
    { statusCode: 401, code: 'UNAUTHORIZED' }
  );
});

test('auth middleware throws 401 with missing X-API-Key', () => {
  const middleware = createAuthMiddleware({ apiKey: 'secret-123' });
  assert.throws(
    () => middleware({ headers: {} }, {}, {}),
    { statusCode: 401, code: 'UNAUTHORIZED' }
  );
});
```
</action>
